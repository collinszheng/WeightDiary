## M3 · 图表（自绘 Canvas）

> **状态：🚧 进行中（第 1–7 步已完成，第 8–9 步待做）**
>
> 已完成：区间解析 / 聚合 / 刻度 / 平滑四个领域模块（96 个单测全绿）+ Tab 栏 + 日期范围箭头 + 静态 Canvas 绘制。
> 待做：**视口滚动与手势方向判定**、**数据点点击气泡与命中测试**。
>
> 实现时发现并修掉的两个真 bug 记在 [03 技术设计 §4.4](03-技术设计.md)：
> Y 轴上界可能低于数据最大值导致折线被裁、以及极小跨度会选出两位小数的次步长。

> **本阶段是项目最大的风险点**，建议按下面的顺序做，每步都能单独验证。

### 建议实现顺序

| 步 | 内容 | 可验证的产出 |
|---|---|---|
| 1 | `RangeResolver`：Tab + 基准日期 → (start, end, granularity) | 单测：5 个 Tab × 边界日期 |
| 2 | `Aggregator`：按粒度聚合，**当日最低值锁定同一条记录** | 单测：一天多条时三个指标来自同一记录 |
| 3 | `ChartScaffolder`：Y 轴 13 条刻度、X 轴刻度位与 5 个标签位置 | 单测：各种数据跨度下的主/次步长 |
| 4 | `MonotoneCubic`：Fritsch–Carlson + Hermite→Bezier | 单测：**不过冲**、保单调、1 点 / 2 点退化 |
| 5 | 静态 Canvas：只画刻度线 + 折线 + 数据点 | 屏幕上能看到图 |
| 6 | 渐变填充 + 目标虚线 + 轴文字 | 与设计稿对照 |
| 7 | Tab 切换与日期范围箭头 | 交互闭环 |
| 8 | 视口滚动 + 手势方向判定 | 与页面纵向滚动不打架 |
| 9 | 点击命中测试 + 气泡 | 点数据点出详情 |

### 交付

- [ ] 图表卡片：Tab 栏、日期范围选择器、绘图区
- [ ] Y 轴：4 条带数字主刻度 + 9 条次刻度 = **13 条**
- [ ] X 轴：**不画任何刻度线**，只画 5 个日期文字
- [ ] 折线：monotone cubic 平滑、2dp、`#3DD68C`、**跨空缺为实线**
- [ ] 渐变填充、空心实测点、虚线目标线（在折线之下）
- [ ] 日 / 周 / 月 / 年 / 总 五个视图
- [ ] 左右箭头切范围；图表内滑动滚视口；边缘回弹
- [ ] 数据点点击气泡

### 出口标准

- [ ] Y 轴恰好 4 个数字标签，**全部是整数**，且范围包含目标体重
- [ ] Y 轴共 13 条水平刻度线
- [ ] X 轴 5 个标签位置**严格四等分**（含数据有缺口的月份）
- [ ] X 轴**不出现任何刻度线**
- [ ] 折线**不出现过冲**：曲线任何位置的取值都在相邻两点值域内
- [ ] 跨越未记录日期时是**实线**，无虚线
- [ ] 空心点只出现在真实记录位置
- [ ] 图表内左右滑动**不改变**日期范围
- [ ] 手指落在图表上纵向滑动时，**页面能正常滚动**
- [ ] 退化场景不崩不空白：0 条 / 1 条 / 全部相同

### 注意

- ⚠️ **手势三层嵌套**：图表横向 ↔ 页面纵向 ↔ 概览卡片横向。必须在 `pointerInput` 做方向判定，只消费一个方向（[技术设计 · R5](03-技术设计.md)）
- ⚠️ **视口滚动在「日 / 周」视图无效果**（点数太少），M3 需确认接受还是改为切范围（[技术设计 · R10](03-技术设计.md)）
- ⚠️ **「当日最低值」必须锁定同一条记录**，不能三个指标各自取最小
- ⚠️ 目标与数据差值超过区间 30% 时，**不撑开 Y 轴**，改为边缘方向箭头
